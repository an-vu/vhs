# vHuman Studios

Website for [vHuman Studios](https://vhumanstudios.com).

## Local Preview

From the project root, run:

```bash
python3 dev/serve.py
```

Open the printed URL from your Mac or another device on the same Wi-Fi. If `en0` has no IP, the script uses `http://localhost:6969`.

Stop the server with:

```text
Ctrl + C
```
